💡 Tips Konfigurasi Wake-on-LAN pada PC Target:

  • BIOS / UEFI: Pastikan opsi Wake on LAN, PCIe Power On, atau EuP / ErP Ready diatur ke Enabled (atau ErP di-Disable agar kartu jaringan tetap mendapat daya standby saat PC mati).
  • Windows: Buka Device Manager → Network Adapters → Klik kanan LAN Card → Properties → Power Management → Centang Allow this device to wake the computer dan Only allow a magic packet to wake the computer. Matikan juga opsi "Fast Startup" pada Windows Control Panel jika PC gagal menyala dari status shutdown penuh.
  • Koneksi: Disarankan menggunakan kabel LAN ethernet untuk reliabilitas Wake-on-LAN tertinggi.

💡 Di mana mendapatkan Webhook?

1. ntfy.sh (Notifikasi ke HP - Paling Mudah!) GRATIS

Tanpa daftar akun! Install aplikasi ntfy di HP (Android/iOS), buat topik rahasia Anda sendiri, misal:

https://ntfy.sh/rumah-alif-alert

Tempel link tersebut di atas, notifikasi langsung bunyi di HP Anda!

2. Discord Webhook

Di Discord server Anda → Klik kanan Channel → Edit Channel → Integrations → Webhooks → Klik Copy Webhook URL.

3. Edit File Langsung di Server

Anda juga bisa mengedit file konfigurasi server secara langsung di:

/home/alif/home-monitor/data/config.json
